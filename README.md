# Chinese Multimodal News Forgery Dataset

This repository accompanies the manuscript **A Chinese Multimodal News Dataset with Multiple Forgery Types: Construction and Benchmarking**.

The study presents a Chinese news dataset constructed from source-traceable reports collected from the Sina News platform. It includes original news reports and four categories of controlled forgery: text manipulation, image manipulation, cross-event image-text mismatch, and joint text-image forgery. The labels describe the construction operations performed in this study; they do not constitute independent fact-checking judgments about the original reports.

## Current availability

This repository currently contains project documentation only. Dataset files and benchmark evaluation code have not yet been uploaded and are not currently available for download. The repository does not currently provide the materials needed to reproduce the reported benchmark results.

## Planned release

We plan to make the following materials publicly available upon publication of the paper:

- Dataset labels and sample identifiers
- The fixed training, validation, and test splits used in the paper
- Source indices and references to the original reports, where sharing is permitted
- Documentation of the construction procedures and label definitions
- Benchmark evaluation code and configuration files

This list describes a planned release, not materials that are already available. This README will be updated with file descriptions and access instructions as materials are released.
